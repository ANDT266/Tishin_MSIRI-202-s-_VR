1 Лекция 

1. Чем класс отличается от объекта?

Класс — это шаблон или чертёж, по которому создаются объекты. Он описывает свойства (поля) и действия (методы).

Объект — это конкретный экземпляр класса, созданный на основе этого шаблона.

2. Что хранит переменная класса?

Переменная, объявленная с типом класса, обычно хранит ссылку на объект, созданный на основе этого класса.

3. Что произойдёт при обращении к члену через null-ссылку?

Если попытаться обратиться к полю или вызвать метод через ссылку со значением null, в Java возникнет исключение NullPointerException.

Ошибка возникает потому, что поле не ссылается ни на какой объект.

4. Зачем объединять поля и методы в одном классе?

Поля и методы объединяют в классе для реализации инкапсуляции — одного из основных принципов ООП.

Инкапсуляция позволяет объединить данные объекта и методы для работы с ними, а также контролировать доступ к внутреннему состоянию объекта.

Пример: класс BankAccount может хранить баланс и предоставлять методы для пополнения и снятия денег.

Это делает программу более структурированной, безопасной, понятной и удобной для изменения и поддержки.

2 Лекция 

1. Зачем скрывать поля класса?

Поля класса скрывают, чтобы защитить внутренние данные объекта от неправильного или неконтролируемого изменения. Обычно для этого используют модификатор private, а доступ к данным организуют через свойства и методы.

Это позволяет контролировать значения, проверять их корректность и сохранять целостность объекта. Такой подход называется инкапсуляцией.

2. Чем свойство отличается от поля?

Поле — это переменная внутри класса, которая непосредственно хранит данные объекта.

Свойство — это специальный член класса, через который можно получать и изменять значение. Оно использует методы доступа: get для чтения и set для записи. Внутри set можно проверять новое значение.

Например, поле может хранить возраст, а свойство Age — разрешать устанавливать только положительное значение.

3. Что произойдёт, если не объявить ни одного конструктора?

Если в классе не объявлен ни один конструктор экземпляра, компилятор автоматически создаёт конструктор без параметров. Он позволяет создать объект с начальными значениями полей по умолчанию.

Если в классе объявить хотя бы один собственный конструктор, автоматический конструктор без параметров обычно уже не создаётся.

4. Как конструктор связан с инкапсуляцией?

Конструктор помогает реализовать инкапсуляцию, потому что задаёт начальное состояние объекта при его создании. Через параметры конструктора можно передать необходимые значения и проверить их корректность.

Таким образом, объект создаётся сразу в допустимом состоянии, а его внутренние данные не приходится изменять напрямую.

5. Можно ли изменить свойство только для чтения после создания объекта?

Обычно свойство только для чтения нельзя изменить извне после создания объекта. Его значение можно задать при объявлении или внутри конструктора, а затем только считывать.

В C# свойство с get без set можно инициализировать в конструкторе. Свойство с init можно установить во время создания объекта, но нельзя свободно менять после завершения инициализации.
